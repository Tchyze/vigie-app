Correctifs d'affichage pour les produits dont les sources ne publient pas les versions
(aujourd'hui Cisco IOS XE et Stormshield SNS : seules leurs dates de fin de support sont connues).

## Changements

- **Fil** : « Version inconnue » est remplacé par « Versions non publiées par la source », avec
  la date de fin de support de la branche.
- **Détail d'une branche** : explication et invitation à vérifier la dernière version dans les
  notes de version de l'éditeur.
- **Inventaire** : un équipement sur une branche supportée de ces produits n'est plus classé
  « Inconnu » mais « À vérifier », avec la date de fin de support. Les branches en fin de support
  proche ou hors support gardent leur verdict habituel.
- **Saisie d'un équipement** : indication quand la source ne publie pas de versions.

## Installation

La 0.1.0-beta était signée avec une clé debug temporaire : désinstallez-la avant d'installer
celle-ci, après avoir exporté l'inventaire (Réglages › Exporter) si vous en avez saisi un.
