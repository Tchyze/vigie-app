Première version de test de Vigie, l'application qui surveille les mises à jour de vos équipements
et logiciels d'infrastructure (firewalls, switchs, systèmes, services).

## Contenu

- **Fil** : dernières versions des branches suivies, badges sécurité et fin de support proche,
  détail de chaque branche (dates de fin de support, historique des versions, avis liés).
- **Technologies suivies** : produits entiers ou branches une à une.
- **Inventaire** : vos équipements et leur version installée, avec un verdict « suis-je à jour ? »
  (mise à jour disponible, correctif de sécurité manqué, fin de support proche, hors support).
- **Avis de sécurité** : filtrés sur vos technologies et par sévérité.
- **Notifications** en arrière-plan : nouvelles versions, nouveaux avis, fins de support.
- **Réglages** : mode démo, adresse des données, fréquence d'actualisation, export et import de
  l'inventaire.

## À savoir

- Le **mode démo** est activé par défaut : les données sont des exemples embarqués. Désactivez-le
  dans les réglages pour utiliser les données publiées par `vigie-collector`.
- L'inventaire reste uniquement sur le téléphone. **Exportez-le** avant de désinstaller
  l'application ou de changer de téléphone.
- Android 8.0 minimum. Installation hors Play Store : autorisez l'installation depuis l'application
  utilisée pour ouvrir l'APK.
